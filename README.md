# Premium Topic Spinner Wheel — by IMRAN

একটি প্রিমিয়াম, আধুনিক ও আল্ট্রা-স্মুথ প্রেজেন্টেশন ও স্পিচ টপিক স্পিনার হুইল ওয়েব অ্যাপ্লিকেশন।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Features)

- **হোয়াইট প্রিমিয়াম থিম**: Apple / Linear / Vercel অনুপ্রাণিত আধুনিক ও পরিচ্ছন্ন ডিজাইন।
- **টপিক ভিত্তিক স্পিনার হুইল**: বক্তব্য, প্রেজেন্টেশন ও ক্লাসরুম আলোচনার বিষয় নির্বাচনের জন্য আদর্শ।
- **স্থায়ী ডেটা সংরক্ষণ (Never Auto-deleted)**: যেকোনো টপিক একবার যুক্ত করলে তা ব্রাউজারের `localStorage`-এ স্থায়ীভাবে সংরক্ষিত থাকে এবং ব্যবহারকারী নিজে না মোছা পর্যন্ত কখনোই মুছে যায় না।
- **বক্তব্যের নির্দেশনা ও টাইমার পপআপ**: স্পিন শেষ হলে স্বয়ংক্রিয়ভাবে নির্বাচিত টপিকটি প্রদর্শিত হয় এবং স্পিকারকে বক্তব্য শুরু করার নির্দেশনার পাশাপাশি একটি ইন্টারেক্টিভ ১-৩ মিনিটের বক্তব্য টাইমার দেওয়া হয়।
- **ক্যানভাস ২ডি স্পিনার হুইল (Canvas 2D API)**: কোনো এক্সটার্নাল লাইব্রেরি ছাড়াই সরাসরি ক্যানভাসে রেন্ডার করা হয়েছে, যা যেকোনো ডিভাইসে আল্ট্রা-স্মুথ ও দ্রুতগতির।
- **বাটার-স্মুথ অ্যানিমেশন ও প্রসিডিউরাল অডিও**:
  - ফিজিক্স ভিত্তিক ডিক্লিরেশন ও মাইক্রো বাউন্স-ব্যাক।
  - প্রতিটি স্লাইস অতিক্রম করার সময় পয়েন্টারের ইলাস্টিক টিক অ্যানিমেশন।
  - Web Audio API দিয়ে তৈরি রিয়েল-টাইম সাউন্ড ও মিউজিক।
- **টপিক ব্যবস্থাপনা**:
  - কমা বা নিউ-লাইন দিয়ে একসাথে একাধিক টপিক যুক্ত করার সুবিধা।
  - সর্বোচ্চ ১০০টি টপিক সমর্থন।
- **স্পিন ইতিহাস**: বিগত ১০টি নির্বাচিত টপিকের রেকর্ড।
- **মোবাইল-ফার্স্ট রেসপনসিভ**: যেকোনো মোবাইল ও ডেস্কটপ স্ক্রিনে পারফেক্ট স্কেলিং।

## 🚀 Render-এ হোস্ট করার সহজ উপায় (Render Deployment Guide)

এই অ্যাপটি একটি ক্লায়েন্ট-সাইড স্ট্যাটিক সিঙ্গেল পেজ অ্যাপ্লিকেশন (SPA), তাই Render-এর **Static Site** ফিচারে এটি আজীবন **১০০% ফ্রিতে**, হাই স্পিড গ্লোবাল CDN এবং ফ্রি SSL সহ হোস্ট করা যায়।

### ধাপ ১: GitHub-এ কোড আপলোড করুন
1. কোডগুলো আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরিতে (Repository) পুশ/আপলোড করুন।

### ধাপ ২: Render-এ Static Site তৈরি করুন
1. [Render.com](https://render.com)-এ যান এবং লগইন করুন।
2. ড্যাশবোর্ডের উপরে ডানপাশে **`New +`** বাটনে ক্লিক করে **`Static Site`** নির্বাচন করুন।
3. আপনার GitHub রিপোজিটরিটি সিলেক্ট / কানেক্ট করুন।

### ধাপ ৩: সেটিংস কনফিগার করুন
- **Name**: `imrans-spinner` (অথবা আপনার পছন্দের যেকোনো নাম)
- **Branch**: `main`
- **Build Command**: `npm install --legacy-peer-deps && npm run build`
- **Publish Directory**: `dist`

### ধাপ ৪: ডিপ্লয় করুন
- নিচে **`Create Static Site`** বাটনে ক্লিক করুন।
- ১-২ মিনিটের মধ্যে সাইটটি লাইভ হয়ে যাবে এবং Render আপনাকে একটি ফ্রি লাইভ লিঙ্ক (যেমন: `https://imrans-spinner.onrender.com`) প্রদান করবে!
